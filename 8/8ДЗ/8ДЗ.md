## Задача 1

**Условие:** для мультипликативной группы поля `GF(5^2)`, считая `x` примитивным элементом, определить порядки всех элементов поля.

### 1. Теория

Поле `GF(5^2) = GF(25)` содержит 25 элементов.

Мультипликативная группа ненулевых элементов поля имеет порядок:

```text
25 - 1 = 24
```

Из теории конечных полей известно, что группа ненулевых элементов поля `GF(25)` циклическая.
Если `x` — примитивный элемент, то он порождает всю группу, то есть:

```text
GF(25)* = <x>,   ord(x) = 24
```

Каждый ненулевой элемент поля можно записать в виде `x^k`, где `k = 0, 1, ..., 23`.
Тогда порядок элемента `x^k` вычисляется по формуле:

```text
ord(x^k) = 24 / gcd(24, k)
```

Элемент `0` не входит в мультипликативную группу, поэтому его мультипликативный порядок не определён.

### 3. Группировка по порядкам

- Порядок `1`: `1`
- Порядок `2`: `x^12`
- Порядок `3`: `x^8`, `x^16`
- Порядок `4`: `x^6`, `x^18`

- Порядок `12`: `x^2`, `x^10`, `x^14`, `x^22`
- Порядок `24`: `x`, `x^5`, `x^7`, `x^11`, `x^13`, `x^17`, `x^19`, `x^23`

### 4. Ответ по задаче 1

Для любого ненулевого элемента `x^k` поля `GF(25)`:

```text
ord(x^k) = 24 / gcd(24, k)
```

Элемент `0` мультипликативного порядка не имеет.

## Задача 2

**Условие:** для кодера `(15,4)`-кода с проверочным полиномом

```text
h(x) = 1 + x + x^4
```

описать смену состояний регистра при начальном заполнении `0, 0, 1, 1`,
убедиться, что это код максимальной длины,
определить минимальное расстояние этого кода.

### 1. Рекуррентное соотношение

Полином

```text
h(x) = 1 + x + x^4
```

задаёт линейную рекурсию над `GF(2)`:

```text
a(i+4) = a(i+1) XOR a(i)
```

Состояние регистра на шаге `i` будем записывать так:

```text
S(i) = (a(i), a(i+1), a(i+2), a(i+3))
```

Тогда переход к следующему состоянию имеет вид:

```text
(a(i), a(i+1), a(i+2), a(i+3))
-> (a(i+1), a(i+2), a(i+3), a(i) XOR a(i+1))
```

Начальное состояние:

```text
S(0) = (0, 0, 1, 1)
```

То есть стартовое содержимое регистра:

```text
0011
```

### 2. Смена состояний регистра

| Шаг i | Состояние | Новый бит = a(i) XOR a(i+1) | Следующее состояние | Выходной бит |
|------:|-----------|------------------------------|---------------------|--------------|
| 0  | 0011 | 0 | 0110 | 0 |
| 1  | 0110 | 1 | 1101 | 0 |
| 2  | 1101 | 0 | 1010 | 1 |
| 3  | 1010 | 1 | 0101 | 1 |
| 4  | 0101 | 1 | 1011 | 0 |
| 5  | 1011 | 1 | 0111 | 1 |
| 6  | 0111 | 1 | 1111 | 0 |
| 7  | 1111 | 0 | 1110 | 1 |
| 8  | 1110 | 0 | 1100 | 1 |
| 9  | 1100 | 0 | 1000 | 1 |
| 10 | 1000 | 1 | 0001 | 1 |
| 11 | 0001 | 0 | 0010 | 0 |
| 12 | 0010 | 0 | 0100 | 0 |
| 13 | 0100 | 1 | 1001 | 0 |
| 14 | 1001 | 1 | 0011 | 1 |

После 15-го сдвига регистр вернулся в исходное состояние `0011`.

Если в качестве выходной последовательности брать левый разряд текущего состояния, то за один период получаем:

```text
001101011110001
```

### 3. Проверка, что код максимальной длины

Степень полинома `h(x)` равна 4.

Для линейного регистра сдвига максимальная возможная длина периода равна:

```text
2^4 - 1 = 15
```

Из таблицы видно, что:

1. регистр проходит через 15 различных ненулевых состояний;
2. только после этого возвращается в исходное состояние `0011`.

Следовательно, период действительно равен 15, а это максимальное возможное значение.

**Вывод:** данный код является кодом максимальной длины.

### 4. Минимальное расстояние кода

Дан `(15,4)`-циклический код.

Так как степень проверочного полинома `h(x)` равна 4, порождающий полином равен:

```text
g(x) = (x^15 + 1) / h(x)
     = x^11 + x^8 + x^7 + x^5 + x^3 + x^2 + x + 1
```

Этот код является бинарным симплекс-кодом с параметрами:

```text
[15, 4, 8]
```

То есть:

- длина `n = 15`
- размерность `k = 4`
- минимальное расстояние `d_min = 8`

Следовательно:

```text
d_min = 8
```

Также это можно сформулировать так: все ненулевые кодовые слова имеют вес 8, поэтому минимальное расстояние равно 8.

### По задаче 2

Для полинома

```text
h(x) = 1 + x + x^4
```

регистр с начальным состоянием `0011` проходит 15 различных ненулевых состояний и возвращается в исходное состояние только на 15-м шаге.

Следовательно, код имеет максимальную длину.

Параметры кода:

```text
[15, 4, 8]
```

Минимальное расстояние:

```text
d_min = 8
```
